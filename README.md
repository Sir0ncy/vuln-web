# Vuln Web App

A simple, intentionally vulnerable web application built with PHP, MySQL, and Tailwind CSS. This project is designed specifically for practicing SQL Injection (SQLi) techniques on a login form in a safe, isolated, and containerized environment.

## How 2 Run

1. Navigate to the project directory & Build and start the containers
```bash
docker-compose up -d

2. Open it
Open your web browser and go to: http://localhost:8000
